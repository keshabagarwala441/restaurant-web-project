# 🍽️ Delizia Restaurant Website

A modern, responsive multi-page restaurant website built using **HTML5, CSS3 and JavaScript**.

## Features

- Responsive Design
- Modern UI
- Sticky Navigation
- Hero Section
- About Page
- Food Menu
- Menu Search
- Menu Filter
- Price Sorting
- Gallery with Lightbox
- Reservation Form
- Contact Page
- Google Maps
- Smooth Scrolling
- Scroll Animations
- Back To Top Button
- Mobile Friendly
- SEO Friendly
